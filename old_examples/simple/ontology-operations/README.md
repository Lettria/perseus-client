# Ontology Operations Example ⚙️

This script shows how to upload and verify an ontology using the Perseus client. Simple and sweet! ✨

## Quick Start 🚀

1.  **Setup Environment**:
    - Python 3.8+ required. 🐍
    - Copy `template.env` to `.env` and fill your credentials.

    ```bash
    cp template.env .env
    # Edit .env with your PERSEUS_API_KEY
    ```

2.  **Install Dependencies**:

    ```bash
    pip install -r requirements.txt
    ```

3.  **Run Example**:

    ```bash
    python ontology_example.py
    ```

    This will upload `assets/example_ontology.ttl` and confirm its presence. ✅
